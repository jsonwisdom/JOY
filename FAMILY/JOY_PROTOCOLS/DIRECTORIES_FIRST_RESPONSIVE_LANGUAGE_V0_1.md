## Cross-platform drill rule

When a user invokes connected platforms, preserve the same path discipline independently on each substrate:

```text
GITHUB WORD
→ REPO
→ DIRECTORY
→ FILE / PR / RECEIPT

DRIVE WORD
→ FOLDER
→ SUBFOLDER
→ DOCUMENT / RECEIPT

OPENAI DEVELOPERS WORD
→ ORGANIZATION / PROJECT / PROVIDER SURFACE
→ CAPABILITY / RUNTIME BOUNDARY
```

Cross-provider results may be compared, but one provider's structure does not silently overwrite another's.

```text
GITHUB_COMMIT != DRIVE_REVISION
OPENAI_PROJECT != FAMILY_ROLE
PROVIDER_ACCESS != AUTHORITY
CROSS_PROVIDER_ATOMICITY = FALSE
```

## Responsive-language contract

Before answering or generating a new artifact:

1. Parse the user's nouns/labels as candidate path tokens.
2. Resolve the known root or platform for each token.
3. Drill one level per additional qualifier, repeating deeper when the user repeats/refines the term.
4. Search variants and prior lineage before minting a new node/name/layer.
5. Preserve conflicts and historical variants instead of silently normalizing them.
6. Answer or patch only after the observed structure is known.

```text
LOOKUP
→ LINEAGE
→ VARIANTS
→ CURRENT STATE
→ DELTA
```

Not:

```text
REPEATED WORD
→ IGNORE AS REDUNDANT
→ INVENT NEW ABSTRACTION
```
