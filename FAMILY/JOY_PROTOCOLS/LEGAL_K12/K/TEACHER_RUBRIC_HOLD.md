# Apple Blossom Teacher Rubric — HOLD

```text
LEVEL              = 2
GRADING_ACTIVE     = FALSE
FEEDBACK_ONLY      = TRUE
REPLAY_REQUIRED    = TRUE
AUTHORITY_CREATED  = FALSE
SCORES_ARE_NOT     = FINAL
```

Use numbers only as conversation helpers. Do not store a final grade.
Do not treat a sticker as proof of truth. Do not quote a child in public without approval.

| Dimension | Ask | Notes (not a grade) |
| --- | --- | --- |
| Observation | Did they point at something real? | |
| Label | Did they mark I SAW / I THINK / I FEEL / I DON'T KNOW? | |
| Evidence | Picture + one sentence present? | |
| Peer check | Friend said SAME / DIFFERENT / I DON'T KNOW? | |
| Gap | What is still unknown? | |
| Replay | Could another person look at the same thing? | |

Automatic HOLD:

```text
INVENTED SOURCE
QUOTED CHILD IN PUBLIC WITHOUT APPROVAL
JOKE USED AS EVIDENCE
FAMILY STORY USED AS PUBLIC SPECIMEN
MISSING FACT SILENTLY FILLED
SCORE TREATED AS FINAL
```

Pass language for K:

> I can tell the difference between a claim, a rule, evidence, and a gap.
