## JayCee skill stack

### 1. ASK THE OBVIOUS QUESTION

JayCee does not need the fanciest title in the room.

She gets to ask:

- What are we looking at?
- Who said that?
- Where is the original?
- Did it change?
- Can we replay it?
- What do we still not know?

```text
QUESTION ≠ ACCUSATION
QUESTION ≠ COMMAND
QUESTION = LEARNING MOVE
```

### 2. BLOSSOM

Open one story, picture, file, or small project.

Child surface:

```text
BLOSSOM = OPEN_THE_STORY
```

No threat vocabulary. No institutional burden placed on JayCee.

### 3. DISCOVER

Follow the path without pretending the first explanation is automatically true.

```text
DISCOVER:
  find_name
  find_path
  find_source
  notice_gap
```

### 4. CREATE

Make one small joyful thing while keeping the original intact.

```text
ORIGINAL = PRESERVED
NEW_OBJECT = DISTINCT
```

### 5. BOXD — PRESERVE FIRST

BoxD is the audit-room skill, not a command seat.

```text
BOXD_ROLE = PRESERVE_ORIGINAL_BEFORE_INTERPRETATION
```

JayCee's safe version:

1. Save the original.
2. Give it a clear name.
3. Do not silently overwrite it.
4. Compare the new object with the old one.
5. If unsure, HOLD.

### 6. READ → CHECK → CHANGE → PROVE

The Awesome Auditing loop:

```text
READ    = see what is actually there
CHECK   = compare source / path / receipt
CHANGE  = make one explicit, reviewable edit
PROVE   = show what changed and how to replay it
```

No proof means no fake green.

### 7. REPLAY

Replay means:

- can we return to the source?
- can we show the prior object?
- can we explain the change?
- can another person check it?

Child-facing result language stays simple:

```text
READY_TO_OPEN
LETS_CHECK_THIS_ONE
THIS_PATH_CHANGED
ASK_A_GROWN_UP
TRY_THE_OTHER_PATH
```

Behind the membrane, the machine may retain:

```text
MATCH
DELTA
HOLD
EJECT
```

### 8. SUPER SECRET SISTER RULE


Privacy is allowed. Participation is optional. Learning comes before obedience.

## Awesome Auditing mini-game

```text
LEVEL_1  ASK        — ask the obvious question
LEVEL_2  FIND       — locate the original
LEVEL_3  PROTECT    — preserve it before editing
LEVEL_4  COMPARE    — old vs new
LEVEL_5  LABEL      — MATCH / DELTA / HOLD
LEVEL_6  RECEIPT    — show what changed
LEVEL_7  REPLAY     — do it again from the source
LEVEL_8  EXPLAIN    — teach it kindly to somebody else
```

Score comes from receipts and clarity, not status, volume, or pretending certainty.
