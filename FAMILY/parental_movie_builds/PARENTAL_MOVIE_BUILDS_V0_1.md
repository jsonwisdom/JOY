## Purpose

Parental Movie Builds turns a shared movie into a family-safe build prompt.

A movie is a cultural starting point. It is not evidence about a daughter, a private profile, a behavioral score, or a verdict.

```text
WATCH
→ NOTICE
→ ASK
→ MATRIX
→ BUILD
→ RECEIPT
→ REPLAY
```

## Three Daughters order

1. PROTECT — protect daughters and private family context first.
2. PRESERVE — preserve distinct memories, questions, refusals, and versions.
3. EXPAND — build only after the first two boundaries hold.

## Parent / daughter boundary

- Jay may offer a prompt, explain his own reasoning, and build his own MatrixMathbyJay example.
- A daughter may join, change the prompt, preserve a different interpretation, pause, refuse, or remain silent.
- Participation does not create consent beyond the selected movie-build session.
- A GitHub artifact does not speak for a daughter.
- No daughter response is required for the parent build to remain valid as Jay's own work.
- No private family detail belongs in the public repository.

## MatrixMathbyJay

MatrixMathbyJay is Jay's transparent reasoning surface:

```text
SOURCE SCENE / THEME
→ OBSERVATION
→ QUESTION

→ EVIDENCE NEEDED
```
