## GroundZeroDay Lesson

GroundZeroDay begins at the search method, not at the conclusion.

If the first query fails, replay the vocabulary before promoting absence.

```text
CHILD_TOKEN_SEARCH
-> SEARCH_MISS
-> HOLD
-> IDENTIFY_SEMANTIC_PARENT
-> REPLAY_SEARCH
-> COMPARE_RESULTS
-> PRESERVE_NON_JOIN_MEMBRANES
-> TEACH_BACK
```

The correction is methodological: improve retrieval without changing the evidence standard.
