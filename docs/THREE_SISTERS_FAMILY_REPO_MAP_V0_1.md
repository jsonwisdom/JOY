## Three Sisters function set

The model uses three reusable functions rather than assigning permanent identities:

```text
ANCHOR  -> preserve memory without rewriting people
BRIDGE  -> translate without distorting or demanding sacrifice
SPARK   -> protect curiosity and the right to ask why not
```

A fourth witnessing function may operate alongside them:

```text
OBSERVER -> name what is seen without creating execution authority
```

Confirmed repositories may implement one or more functions only through explicit operator confirmation. No function is inferred from a person's name.

## MARYDEE sister check

Before a family-field transition:

```text
[ ] Is memory being honored rather than overwritten?
[ ] Is translation preserving each person's meaning?
[ ] Is curiosity welcomed rather than punished?
[ ] Is observation heard without forcing action?
[ ] Is anyone being silenced to manufacture harmony?
[ ] Is anyone elevated at another person's expense?
[ ] Is participation voluntary?
[ ] Is the system becoming less necessary over time?
```

Any unresolved answer produces `PAUSE` or `REVIEW_REQUIRED`; it does not create authority.
