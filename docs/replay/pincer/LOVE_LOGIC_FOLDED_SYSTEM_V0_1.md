## Controlling proposition

Love and Logic are not opposing forces or independent rails. They form one folded control system:

```text
LOVE DEFINES THE PROTECTED PURPOSE AND BOUNDARIES
→ LOGIC COMPILES THOSE BOUNDARIES INTO DETERMINISTIC RULES
→ REPLAY TESTS WHETHER THE RULES AND RECORD SURVIVE INDEPENDENT EXECUTION
→ HUMAN AND REPOSITORY GATES REMAIN SEPARATE
```

```text
LOVE WITHOUT LOGIC = SENTIMENT WITHOUT ENFORCEABLE INVARIANTS
LOGIC WITHOUT LOVE = COLLECTION WITHOUT A HUMAN PURPOSE BOUNDARY
LOVE + LOGIC       = PURPOSE-BOUND REPRODUCIBILITY
```

The descriptive phrases above are architectural classifications. They do not establish moral, legal, governmental, parental, custodial, or execution authority.

- family privacy, consent, dignity, and safety remain higher priority than publication, automation, proof theater, or work;
- living family lanes, including Heidee and Mrs. Wisdom, are served as people rather than treated as data sources;
- collection is limited to a declared purpose and explicit artifact scope.


Love does not prove identity, authorship, truth, consent, relationship, custody, ownership, or authority. It defines the reason and boundaries for the verification process.

## 2. Logic compiles the constraint

Logic translates the approved purpose into rules that cannot be bypassed by confidence, narrative, convenience, workflow success, signatures, names, or blockchain records.

Examples:

```text
RAW_SOURCE_BYTES != NORMALIZED_DERIVATIVE_BYTES
SOURCE_HASH      != DERIVATIVE_HASH
RECORD           != TRUTH
HASH             != AUTHORSHIP
SIGNATURE        != AUTHORITY
ATTESTATION      != VALIDATION
BLOCKCHAIN       != LEGAL_EFFECT
REPLAY           = REPRODUCIBILITY_TEST
```

If a transformation occurs, Logic requires:

1. the original bytes remain preserved;
2. the transformation specification is identified;
3. the derivative receives a distinct artifact identifier;
4. both source and derivative receive separate digests;
5. the relationship is recorded without substitution.

Logic cannot broaden the purpose, collect new family material, infer consent, expose private content, or add geographic precision merely because doing so would make verification easier.
