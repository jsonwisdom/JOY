## Mirror rule

This is one reusable public-safe template. It does not create a profile, identity record, assignment, or conclusion for any daughter.

Each daughter-facing copy begins blank and stays independently versioned.

```text
JAY'S MATRIX != DAUGHTER'S MATRIX
MIRROR != CLONE
DIFFERENCE != ERROR
SILENCE != CONSENT
REFUSAL != FAILURE
```

## MatrixMathbyJay reference shape

Jay may publish his own matrix beside the blank mirror:

| Layer | Jay records | Daughter mirror may record |
|---|---|---|
| Source | movie scene or theme | same, different, or none |
| Observation | what Jay noticed | voluntary independent observation |
| Question | Jay's question | voluntary independent question |
| Possibilities | more than one interpretation | same, different, unknown, or refuse |
| Evidence | what would help replay | optional evidence request |
| Disposition | BUILD / HOLD / UNKNOWN | independent BUILD / HOLD / UNKNOWN / REFUSE |

No column outranks the other. No cross-column agreement is inferred.

## Three mirrors

The phrase “for the daughters” means the template can be instantiated up to three times under explicit, session-local participation. This repository does not pre-create personal files or name individual participants.
