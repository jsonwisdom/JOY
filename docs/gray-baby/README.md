# Gray Baby Generator — Public Homepage v0.1

Public, static Gray Baby prompt generator for the JOY GitHub Pages surface.

## Route
Intended GitHub Pages path:

`/JOY/gray-baby/`

## What works without a backend
- user-defined Gray Baby scenarios
- universe seed buttons
- format and mood selection
- reference-image awareness without uploading the file
- three Labyrinth branches: Cinematic / Storybook / Wildcard
- copy individual prompts or all branches
- responsive public homepage

## What does not happen in the static page
- no API calls
- no uploaded images
- no account creation
- no analytics added by this artifact
- no OpenAI key in browser
- no claim that generated art is evidence

## Files
- `index.html` — public UI
- `styles.css` — visual system
- `app.js` — local prompt builder
- `skill.md` — portable Gray Baby Skill Artist prompt
- `OPENAI_ADAPTER.md` — server-side OpenAI integration boundary
