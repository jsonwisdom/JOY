## Purpose

This replay overlay extends the existing public-safe Wisdom Family purpose map without rewriting the frozen family stack or promoting family claims.

**Radiance** = the public-safe contribution signal already declared for a lane. It is not personality proof, likeness consent, biography, or authority.

**Resilience** = the repair and replay behavior used when information is missing, conflicted, misspelled, or drifted. It is not a health, trauma, or psychological claim.

## Operating Loop

```text
MIND THE GAP
    ↓ mark missing / unknown / conflicted / unsupported
LOG THE MAP
    ↓ record lane / source / status / boundary / unresolved gap
REPLAY JAY
    ↓ replay source → map → delta → repair receipt → human review
```
