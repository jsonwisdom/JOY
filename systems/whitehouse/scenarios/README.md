# Scenarios

This directory contains hypothetical scenario packets for the White House Edition module.

Each scenario must be clearly marked as hypothetical unless it references a real public document, and even then it must not claim official authority.

```text
SIMULATION_ONLY           = TRUE
OFFICIAL_AFFILIATION      = FALSE
FEDERAL_AUTHORITY         = NONE
EXECUTION_AUTHORITY       = FALSE
RECEIPTS_CREATE_AUTHORITY = FALSE
```

Scenarios may explore procedural modeling, institutional constraints, hypothetical pressure pathways, boundary tests, and replayable civic structures.

Scenarios may not create government authority, impersonate officials, issue legal commands, claim official status, or imply binding executive power.
