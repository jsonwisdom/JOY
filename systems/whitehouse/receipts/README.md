# Receipts

This directory contains semantic receipts for the White House Edition module. They preserve witness, context, and continuity; they do not create authority.

```text
RECEIPTS_CREATE_AUTHORITY = FALSE
OFFICIAL_AFFILIATION      = FALSE
FEDERAL_AUTHORITY         = NONE
EXECUTION_AUTHORITY       = FALSE
SIMULATION_ONLY           = TRUE
```

A receipt may record that a replay occurred, a boundary check passed, a scenario was explored, an observation was preserved, or a module state changed.

A receipt may not create legal authority, executive power, federal status, official affiliation, or a binding obligation.

Receipts follow `systems/whitehouse/schemas/receipt.schema.json`.
