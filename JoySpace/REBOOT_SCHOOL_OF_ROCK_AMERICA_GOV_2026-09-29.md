## Today's riff

**An answer on a screen is the start of an audit, not the end of one.**

A screen may show an answer. To know what happened, we save the exact answer, follow its source links, check how the answer was made, and ask someone else to replay the same test. The class may question the screen without claiming that the site was attacked or that anyone was targeted.

## Six separate pieces

| Surface | Save or test | State now |
| --- | --- | --- |
| 1. Site instance | Exact URL, access path, environment, and observation time. An instance label alone is not the answer. | OPEN · EMPTY |
| 2. Answer capture | Exact prompt and response, timestamp with time zone, capture method, screenshots or raw export, cited links, and content hashes where possible. | OPEN · EMPTY |
| 3. Source binding | Preserve each cited source object and check whether the cited passage supports the answer's specific claim. | OPEN · EMPTY |
| 4. Component check | Identify the relevant component/version and test the observed behavior against a bounded claim. | OPEN · EMPTY |
| 5. Receipt candidate | Assemble provenance, limitations, contradictions, and status without turning a candidate into a finding. | OPEN · EMPTY |
| 6. Independent replay | A separate operator repeats the bounded prompt and checks agreement or divergence, with their own dated capture. | OPEN · EMPTY |

`N_SURFACES_OPEN=6` does not mean `N_STEPS_TAKEN=6`.  
`SIX_OPEN_EMPTY=ZERO_ANSWER_EVIDENCE`. Reopening an empty surface does not move state.

## ThreeDaughtersReverse: say it backward

1. **Can a friend replay it?** If no one has the exact question and answer, stop.
2. **Can we show the receipt?** If the dated capture is missing, the receipt candidate stays empty.
3. **Can we check the machine part?** A component guess is not a component check.
4. **Can we open the cited source?** A link title is not proof that the source says the same thing.
5. **What did the screen actually say?** Record its exact words and links before telling the story.
6. **Which screen was it?** Name the URL, instance, time, and access path.

**Kid replay line:** “Show me the screen. Save what it said. Open the link. Check the part. Keep the receipt. Let somebody else try.”
